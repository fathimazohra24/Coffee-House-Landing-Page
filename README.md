# ☕ Coffee House – Modern Landing Page

A visually appealing and responsive coffee shop landing page designed to create an engaging online experience. The project focuses on modern UI design, elegant typography, attractive coffee imagery, and a clean layout that reflects the warmth and charm of a coffee house.

## 🌟 Project Overview

Coffee House is a front-end web development project that showcases a coffee shop through an aesthetically designed landing page. It provides visitors with an overview of the brand, featured beverages, menu offerings, and contact information through an intuitive and user-friendly interface.

## ✨ Features

- **Modern Hero Section:** Eye-catching banner with engaging text and call-to-action buttons.
- **Navigation Bar:** Simple and intuitive navigation for easy browsing.
- **About Section:** Introduces the coffee house and its identity.
- **Coffee Menu:** Displays a selection of coffee and beverage offerings.
- **Featured Products:** Highlights popular coffee choices.
- **Visual Design:** High-quality imagery and an appealing colour palette.
- **Responsive Layout:** Designed to provide a consistent experience across different screen sizes.
- **Contact Section:** Provides essential business and contact information.

## 🛠️ Technologies Used

- HTML5 – Website structure and content.
- CSS3 – Styling, layouts, animations, and responsive design.
- JavaScript – Interactive elements and functionality.

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project directory:

   ```bash
   cd Coffee-House-Landing-Page
   ```

3. Open `index.html` in your browser to explore the website.

## 🎯 Project Objective

The primary objective of this project was to strengthen front-end development skills by building a visually engaging website while applying core concepts of HTML, CSS, JavaScript, responsive web design, and user interface development.
